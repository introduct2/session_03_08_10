## How a task works

1. Read the comment at the top of the file.
2. Write your code where it says `// your code here`.
3. Run the file. The **checks** at the bottom print:
   - ✅ your function returns the right value
   - ❌ something is wrong — the message shows what was expected and what you returned
4. When every line is ✅, the task is done. Commit and move on.

Do not edit the `Checks` section.

## How to run a file

**Browser:** open `index.html`, open the console (`Cmd + Option + J` / `Ctrl + Shift + J`),
change the second `<script src="...">` to your task file, save and refresh.

**Node (VS Code terminal):**

```bash
node -r ./check.js 01-functions/02-task-say-hello.js
```

## Stuck?

1. Read the error in the console — it tells you the line number.
2. Re-read the demo file of that folder.
3. Ask your neighbour.
4. Raise your hand.
